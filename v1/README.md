## 3. 六大技术创新

1. **Unified Multi-M ($M \in [1, 2, 3, 4]$) LDS-x 全投影 GEMV**：覆盖 `qkv_proj`、`gate_up_proj`、`down_proj`、`out_proj` 全部投影矩阵，片上 LDS 激活复用，较官方实现加速 1.55× ~ 3.62×；
2. **权重转置持久零开销缓存**：消除高频解码循环中的动态内存申请与转置拷贝；
3. **Triton Long-KV GQA 全注意力 Prefill 加速**：针对 16 个密集注意力层优选 `BM128/BN64/w8` 算子，64K 单步从 490ms 降至 84ms（提速 5.82×）；
4. **Aiter 线性注意力真实维度补齐**：注入 TP=2 下真实维度（`H=8, HV=24`）配置，消除默认单 Wave 静默回退；
5. **MTP 投机采样与分块调度黄金组合**：锁定 `NEXTN steps=1, draft=2, chunk=8192`；
6. **净室 Stock rocBLAS 高优 GEMM 库**：重新全量选优生成，彻底消除历史基线污染。
