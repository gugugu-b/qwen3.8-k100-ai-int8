张量并行：把模型中较大的矩阵运算按行或列切分到多个 GPU 上并行计算，从而降低单卡显存压力、提升大模型训练或推理速度。

```python
def sum_list(lst):
    total = 0
    for x in lst:
        total += x
    return total
```
