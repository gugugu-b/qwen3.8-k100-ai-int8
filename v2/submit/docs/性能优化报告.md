# Qwen3.8-27B K100-AI SGLang性能优化报告

版本：v2/submit，更新于2026-10-17。按社区要求保留五部分结构。§4为当前本机实测结果，全部取三次正式轮的算术均值；没有把预热计入均值。旧七场景报告已保存至 [历史副本](history/性能优化报告-before-expected-20261017.md)。最终精度／资产准入等未完成项以 [当前材料状态](提交材料状态-20261017.md) 为准。

## 1. 测试环境

- 硬件：每服务2×K100-AI，gfx928，TP2／PP1；用户授权四个独立卡对0,1／2,3／4,5／6,7，同机并行负载保留。各场景卡对见§4，不当作同一隔离实验。CPU为双路Hygon C86 7490，128逻辑CPU、8个NUMA节点；内存、内核、启动前GPU状态见 [宿主原始记录](../logs/v2_benchmark_raw/final/environment/community-official-20261017-c/environment.json)，其中driver字段为null，驱动版本未采集。
- 软件：Ubuntu22.04、DTK2604、Python3.10.12，固定厂商SGLang0.5.12、Torch2.10、Triton3.6、Aiter0.1.5。完整厂商版本、image ID/digest见 [环境声明](../env_declare.yaml)，不是通用PyPI组合。
- 模型：Channel INT8 W8A8，已测31文件／30,902,757,820字节；配置、tokenizer、权重身份已核，量化配方及主办方资产许可仍待补齐。原始模型与ShareGPT SHA记录保留。
- 服务：context67584、FA3、page64、静态显存0.85、运行数32／Graph32、prefill65536／chunk8192、关闭radix、Mamba no_buffer、NEXTN steps1／draft2／topk1、native BF16 one-stage AR guard。客户端C64／128不代表服务运行数64／128。
- 依赖：完整rocBLAS库162文件、Aiter五项配置、固定Lightop overlay与TVM FFI缓存均按SHA固定，只读挂载；候选site与已测二进制未改变。

## 3. 优化与测量方法

| 优化项 | 机制与适用范围 | 源码与证据 |
|---|---|---|
| 继承的INT8 LDS GEMV | 特化M=1/2/3/4、权重转置缓存，保留形状／dtype／对齐筛选及fallback | 完整HIP和sitecustomize |
| 继承的LongKV GQA | 固定镜像Triton完整源上两个精确锚点变换，BM128／BN64／8 warps | 变换前后完整源与真实Diff |
| v2 INT8 tile | 18个M/K/N精确匹配，覆盖Lightop私有LMSlim及独立别名 | tile JSON、分项Diff、历史算子与Graph证据 |
| v2 BF16 native AR guard | 仅BF16／TP2／小于max_size，校验安装版确定性copy-in与二进制身份；其余回退 | 完整Python guard；底层厂商kernel未改 |
| 配置与兼容层 | Aiter配置、MTP及Lightop重复注册兼容修复沿用已测版本 | 配置、完整overlay、来源与SHA |

完整自定义源码、编译／加载／回退和依赖源码边界见 [补丁说明](../patch/README.md)。本次整理没有新增优化或运行GPU。理论机制不替代逐项A/B，也不把历史tile-only Graph PASS写成最终组合全模型Graph通过。

随机：seed20260912，4096／65536输入、1024输出、ignore_eos；两轮各C请求预热、三轮各max(8,2*C)正式。ShareGPT：固定数据SHA，context67584，一轮1000完整预热、三轮各1000正式，每次另64短预热。两类协议独立记录。正式采样未开启Profiler／trace。
